判断题常考辨析点
绪论与自由度
零件与构件没有包含关系：零件是最小制造单元，构件是最小运动单元。
计算自由度前先处理复合铰链、局部自由度和虚约束。
m 个构件在同一处组成复合铰链，该处转动副数目为 m − 1。
机构具有确定运动的条件：F > 0，且自由度数等于原动件数。
四连杆与凸轮
压力角与传动角互为余角：α + γ = 90°。
死点位置传动角 γ = 0。
等速运动规律有刚性冲击；等加速等减速、简谐运动规律有柔性冲击。
齿轮与轮系
标准直齿圆柱齿轮不根切的最少齿数为 17。
一对渐开线齿轮的正确啮合条件：模数相等、压力角相等。
渐开线齿轮传动比与安装中心距的微小误差无关（可分性）。
行星轮系自由度为 1，差动轮系自由度为 2。
混合轮系传动比不能用统一公式一次算出，须先分解为定轴轮系和周转轮系再联立求解。
其他章节
飞轮调节周期性速度波动，非周期性速度波动用调速器。
带传动的弹性滑动不可避免，打滑可以避免。
蜗杆传动自锁条件：导程角小于或等于当量摩擦角。
螺纹连接自锁条件：螺纹升角小于或等于当量摩擦角。
滚动轴承基本额定寿命对应的可靠度为 90%。

更安全的用法：后端代理方案
本站目前没有后端代理，以下是方案说明、尚未实现
本站是部署在 GitHub Pages 上的纯静态页面，没有后端服务器。所以 Gemini API Key 只能存在你自己的浏览器里（localStorage），每次提问都由你的浏览器直接发给 Google（或你填的 API 链接）。本站不会把 Key 发给任何其他地方，但只要 Key 在浏览器里，它就有被同源脚本读到的理论风险。
代理的最小可行架构
浏览器 → 你自己的代理服务 → Google Gemini。代理持有 Key（存在服务端的环境变量里，不进仓库、不进浏览器）；浏览器每次只向代理要一个短期凭证（比如 10 分钟有效的 token），提问时把短期凭证发给代理，由代理换成真正的 Key 去调 Gemini，再把答案返回。浏览器里永远没有长期有效的 Key。
部署步骤（概要）
1）在 Cloudflare Workers、Vercel Functions 或你自己的服务器上部署一个很小的转发服务，只接受本站域名的请求，只转发到 generativelanguage.googleapis.com；2）把 Gemini Key 写进服务的环境变量，不要写进代码；3）代理给浏览器发短期凭证，并做频率限制；4）本站把 API 链接改成代理地址，并改成发短期凭证而不是 Key。部署与改代码都需要另行实施，本站现在还是浏览器直连模式。
现在的做法
继续用浏览器直连：Key 只存本机，不进源码、不进仓库；自定义 API 链接只填你信任的地址（AI 设置区有风险提示）。

数据模型说明

本站的学习数据存在本机浏览器 localStorage 的 8 个键里。派生数据（正确率、掌握率、6 态、薄弱知识点、推荐、学习趋势）每次打开页面时由源数据现场算，不另存。

知识点状态 · md_learn_v1.points[知识点 id]
read（打开过）/ mastered（已掌握）/ fav（收藏）/ level / note（个人笔记）/ test（自测）/ readDone / masteredBy（selftest / practice / confirm）/ reviews（复习次数）/ masteredTs（掌握时间）。6 态由这些字段现场推导，不另存状态字段。
错题 · md_learn_v1.wrong[]
id / ch / type / stem / ts（最近错误时间）/ firstTs（首次错误时间）/ count（错误次数）/ ans（正确答案）/ exp（解析）/ loc（答案位置）/ points（关联知识点 id）/ part / reason（错误原因）/ note / mastered。关联：错题 → 题目 id → 章节 / 知识点。
题目笔记 / 标记疑难 / 最近学习
md_learn_v1.qnotes[题 id]、flagged[题 id]、last{知识点 id, ts}。笔记按题 id 挂接，不按题干文字。
学习事件与今日目标 · md_learn_v1.events / goals
events{v, since, days{日期:{sec（活跃秒数）, ansQ（答过的题 id）, okQ（答对过的题 id）, pts（打开过的知识点 id）, mastered（当天掌握的知识点 id）}}}，按日聚合，不存逐条事件行；goals{date, master, quiz}。关联：学习记录 → 知识点 id / 题目 id。
刷题记录 · md_quiz_done
{v:3, byId{题 id:{n:答过, r:答对过}}, legacy（迁移前累计题次）, attempts（累计作答次数）}。同一道题只计一次，正确率按 byId 现场算。
看课进度 · md_progress
{v:1, design, drawing}，手动计数（点 + / −），不是系统算出来的。
