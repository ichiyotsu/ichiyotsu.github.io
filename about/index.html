关于这个网站。

一个用来放软件、设计和一些想法的安静角落。它没有数据库，也没有账号系统；能静态解决的事情，就交给静态文件。

静态HTML / CSS / JS，零构建
0追踪脚本 / Cookie
本地字体、图片与脚本
GitHubPages + Discussions

为什么会有它

我做了不少小工具：TokiTodo、Luma、TokiNote、TokiFonts。它们散落在 GitHub 里，功能、截图和设计决定都藏在 README 和 commit 里。这个网站想把这些东西放在一个能慢慢看的地方，而不是另一份简历。

所以它不追求「什么都有」，只保留三件事：软件、设计，以及一个可以说话的花园。

怎么做的

页面是手写的 HTML / CSS / JS，没有框架，也没有构建步骤。字体、图片和脚本都从本站加载；只有花园里的 GitHub 头像来自 GitHub。深色模式、动效和响应式布局都写在同一套设计令牌上。

花园的讨论由 GitHub Discussions 提供。同步脚本会把公开的讨论、作者头像、点赞和评论数写进一个 JSON 文件；发布、点赞和评论本身仍然在 GitHub 上完成，所以你的账号和头像就是你的身份。

一些坚持

  • 先好用，再好玩。动效是标点，不是正文。
  • 数据先属于你。能本地完成的事，不默认上传。
  • 少即是多。没有追踪、没有弹窗、没有自动播放。
