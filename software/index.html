TokiUI Design

一套基于 Material Design3 Expressive 的通用设计语言；TokiNote 只是第一个示例。

TokiUI 是一套通用设计标准，未来会平铺到每一个软件。它不是公开组件库，而是从 TokiNote 开始沉淀的界面规则：颜色有角色，形状有情绪，组件先服务内容。

查看 TokiUI TokiNote 示例

先有层级，再有表情。

颜色、字体、间距、圆角和动效都从同一套角色出发。深色不是简单反色，而是另一套关系。

一套界面语言。

  • Floating DockMD3E 悬浮玻璃 Dock，选中项主色胶囊与展开标签。
  • FABMD3E 圆角主操作，和 Dock 同一行。
  • Collapsing Header随滚动折叠的标题区。
  • Floating Drawer从侧边浮出的导航与文件面板。
  • Settings List分组明确、留白充足的设置列表。
  • Context Menu短按弹出的上下文菜单。

Token 先于截图。

颜色、形状、间距和组件尺寸都能直接复制，不靠口头描述，也不靠「照着这个做」。

tokiui.tokens.json compose/TokiTokens.kt

TokiUI 目前是内部标准，不发布公开包，也不包含 TokiNote 源码。它是面向所有软件的通用标准，TokiNote 只是当前的示例。
