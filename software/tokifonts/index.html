一些做进去的功能。

不是功能清单，更像是几个「为什么它要这样」的切片。

Pro

以开源字体为主，附带更新过的安装教程和问题说明。

CE

社区投稿版本，按自己的审美和使用场景收录，审核后发布。

教程

从不想 root 的换字体方式，到 root 和 Knox 相关的风险，尽量把坑写在前面。

索引

字体不是越多越好。这里会记录版本、适配系统、字形特点和已知问题。

更新

不定期整理资源库和教程；社区反馈会进入下一轮更新。

字体是界面里最安静的品牌。TokiFonts 想做的，是把「换一套字」这件事讲清楚：它改变了什么，会坏在哪里，以及值不值得。
