Luma

把地址栏做成悬浮玻璃胶囊。

网页住进一张圆角卡片，地址栏和工具栏可以停在窗口顶部或底部。它想证明浏览器也可以轻、安静、有一点自己的形状。

GitHub Releases
  • 桌面 + 移动端
  • Electron + WebView
  • Beta 0.1
悬浮地址栏 · 8 种主题色

一些做进去的功能。

不是功能清单，更像是几个「为什么它要这样」的切片。

悬浮地址栏

地址栏和工具栏是一组玻璃胶囊，可以在顶部和底部之间切换，网页会自动为它让位。

多标签

新建、关闭、重开、切换；每个标签有自己的标题、favicon 和加载状态。

本地新标签页

时间、问候、快捷方式和搜索都在本地生成，不联网也能打开。

主题与玻璃

8 种主题色种子，跟随系统 / 浅色 / 深色；玻璃强度可以自己调。

双端一致

桌面用 Electron + Chromium，移动端用 Android WebView，尽量共用同一套视觉和交互。

DESIGN NOTE

浏览器是最难「做得有性格」的软件之一，因为它必须先把网页放好。Luma 的取舍是：把界面收进一个胶囊，把空间还给网页，只在需要的时候浮出来。

再看几张。

界面会变，但这些细节是它一直想保持的手感。
