TokiTodo

待办，专注计时，手机锁与统计。

GitHub 测试版 v0.1.0-beta.1 · APK

测试版包含部分正式版尚未提供的预览功能。

一些做进去的功能。

不是功能清单，更像是几个「为什么它要这样」的切片。

待办，也可以是一组

待办可以置顶、分组、设置时长；待办集让「今天要做什么」不至于摊成一地。

专注计时

大圆环、暂停 / 跳过 / 循环、背景音和可换字体。计时不是惩罚，是一段被保护起来的时间。

手机锁与强制学习

把手机暂时锁住，或者进入强制学习模式。不是靠意志力，而是先把干扰拿走。

统计

周纵览、月度分布和专注历史。数据不追求像报表，而是让你看见时间去了哪里。

我的与数据

外观、备份、局域网 WebUI 和本地数据。默认都在本机，只有检查更新会访问 GitHub。

底栏

待办、专注、锁机和统计收在同一条底栏里，拇指不用离开下半屏。

TokiTodo 的第一原则不是「功能多」，而是「开始得足够容易」。所以它把待办、计时和锁机放在同一个入口，减少在几个 App 之间来回切换的摩擦。
