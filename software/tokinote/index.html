TokiNote

本地笔记软件
目前最完善的一个。

GitHub 正式版 v0.3.5 · APK 测试版 v0.3.7-beta.3 · APK

测试版包含部分正式版尚未提供的预览功能。

一些做进去的功能。

不是功能清单，更像是几个「为什么它要这样」的切片。

笔记

列表 / 网格、置顶、搜索、日历视图和长按预览；编辑器从首图提取主色，让每篇日记有自己的气氛。

相册

文件夹、多选、全屏查看器和双指缩放；文件夹只记录照片引用，不复制或删除原图。

专注

专注 / 短休息 / 长休息，圆角进度环、可自定义时长和专注总结。

外观

动态取色、纯黑、减弱动效、卡片密度和悬浮工具岛。

数据与隐私

本地存储、完整 JSON 备份、回收站保留 14 天；没有账号上报和用户画像。

底栏

一块悬浮工具岛，写作、相册和专注随手切换。

TokiNote 想做的不是「又一个笔记 App」，而是一个你愿意把私人内容放进去的地方。所以它先解决本地、备份和断网可用，再谈同步。
